# CBR-1 Error Codes

:::note
CBR-1's full error code reference is being finalized alongside the WDC One motor controller documentation. This page will be populated with specific fault codes and resolution steps as they're catalogued.
:::

In the meantime, if a status light indicates a fault (blinking amber), record:

1. The exact light pattern observed.
2. What CBR-1 was doing when the fault occurred (idle, driving, under payload, charging).
3. Your CBR-1 serial number.

Send this information to [support@cbirobotics.com](mailto:support@cbirobotics.com) for a diagnosis while the full error code table is being published.
