# Software Integration

CBR-1's onboard compute currently runs on a ROS 1 codebase, with an active **ROS 1 → ROS 2 migration** underway for the broader CBI EOD/demining codebase that CBR-1 shares lineage with.

- ROS 1 users: existing packages and launch files are supported for the current hardware revision.
- ROS 2 users: see the [ROS 2 Quickstart](/docs_software/tutorials/ros2-quickstart) tutorial for the current migration status and available packages.
- The motor controller (WDC One) exposes its interface over the documented protocol in the [Maintenance Manual](/docs_robots/cbr1/maintenance/motor-controller).

Check back for updates as ROS 2 packages are published, or contact [support@cbirobotics.com](mailto:support@cbirobotics.com) for the latest migration status.
