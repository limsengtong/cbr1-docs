# WDC One Motor Controller

CBR-1 uses the WDC One motor controller. Reference documentation was built internally from ELF firmware analysis of the controller.

## Routine Checks

- Inspect motor controller connectors for corrosion or looseness during each preventative maintenance pass.
- Confirm firmware version matches the latest released build (see release notes, distributed via [support@cbirobotics.com](mailto:support@cbirobotics.com)).
- Log any fault codes surfaced by the controller — cross-reference with [Error Codes](/docs_robots/cbr1/error-codes).

## Replacement

Motor controller replacement should only be performed with power fully disconnected, following the reparability-first component swap procedure common to CBI Robotics platforms.
