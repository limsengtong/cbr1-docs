# Preventative Maintenance Schedule

| Interval | Task |
|---|---|
| Every session | Visual inspection, battery/BMS check, e-stop function test |
| Weekly (active use) | Fastener torque check, connector inspection |
| Monthly | Motor controller firmware/version check, drivetrain lubrication check |
| After any 50kg+ payload run | Re-torque all mounting hardware, inspect chassis for stress marks |
| Annually / before storage season | Full battery health check, software update pass |

This schedule reflects standard academic-lab usage patterns; high-usage labs (daily multi-hour operation) should tighten these intervals — contact [support@cbirobotics.com](mailto:support@cbirobotics.com) for a usage-specific plan.
