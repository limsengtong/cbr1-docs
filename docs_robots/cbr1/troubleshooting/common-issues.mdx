# Common Issues

### CBR-1 won't power on
- Confirm the battery is charged and the BMS connector is fully seated.
- Check the main power switch and inline fuse.

### Status lights show solid amber
- Battery is low — recharge using the supplied charger.

### Status lights blinking amber
- A fault is present. Cross-reference the blink pattern with [Error Codes](/docs_robots/cbr1/error-codes).

### No response from joystick or offboard PC
- Confirm the robot is not in emergency-stop state (solid red light).
- Re-check network/Ethernet connection for offboard PC control.
- Re-pair the joystick if using wireless control.

### Reduced traction or drifting under payload
- Confirm payload is within the [tested load range](/docs_robots/cbr1/integration/mechanical#load-ratings) for your surface.
- Check payload balance over the drive axis.

If an issue isn't resolved by the steps above, contact [support@cbirobotics.com](mailto:support@cbirobotics.com) with your CBR-1 serial number and a description of the issue.
