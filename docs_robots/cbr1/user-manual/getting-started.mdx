# Getting Started

1. Install a charged LiPo battery into the battery tray and confirm the BMS connector is fully seated.
2. Power on CBR-1 using the main power switch.
3. Confirm [status lights](/docs_robots/cbr1/user-manual/status-lights) show an idle, fault-free state.
4. Connect a joystick for manual driving, or an offboard PC over Ethernet/Wi-Fi for ROS 2 control — see the [ROS 2 Quickstart](/docs_software/tutorials/ros2-quickstart).
5. When the battery runs low, recharge using the supplied charger before storing.

For custom sensors, payloads, or mounting hardware, continue to the [Integration Guide](/docs_robots/cbr1/integration).
