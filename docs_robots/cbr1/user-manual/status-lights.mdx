# Status Lights

| Pattern | Meaning |
|---|---|
| Solid green | Idle, ready to drive |
| Blinking green | Actively driving / receiving commands |
| Solid amber | Low battery — recharge soon |
| Blinking amber | Fault present — see [Error Codes](/docs_robots/cbr1/error-codes) |
| Solid red | Emergency stop engaged |
| Off | No power / battery disconnected |

If a light pattern doesn't match this table, consult [Troubleshooting](/docs_robots/cbr1/troubleshooting) or contact [support@cbirobotics.com](mailto:support@cbirobotics.com).
