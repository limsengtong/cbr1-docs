# Unboxing CBR-1

1. Inspect the shipping crate for visible damage before opening. Photograph any damage and contact [support@cbirobotics.com](mailto:support@cbirobotics.com) immediately if found.
2. Remove packing restraints and lift CBR-1 from the crate using the chassis handles, not cabling or sensor mounts.
3. Locate the accessory kit, containing the battery tray/BMS harness, charger, and joystick (if included with your order).
4. Verify the contents against your packing list. Report shortages within 5 business days of delivery.
5. Retain the shipping crate for the first 30 days in case a warranty return is needed.
