# R-BOT Overview

R-BOT is CBI Robotics' EOD/demining UGV. 28 units have been sold to end-users through distributors to date, and R-BOT is exclusively distributed by Inert Products (IP Equip).

## Platform Summary

| Spec | Value |
|---|---|
| Class | EOD / demining UGV |
| Distribution | Exclusive — Inert Products (IP Equip) |
| Design philosophy | Reparability-first — standard, easily replaceable components |
| Warranty | 2 years, remote-support component replacement |
| HS code | 8705.90.0000 |
| Ships to | IP partner facility, Scranton, PA |
