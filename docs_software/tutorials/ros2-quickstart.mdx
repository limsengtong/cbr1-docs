# ROS 2 Quickstart

:::note Migration in progress
CBR-1's software stack is being migrated from ROS 1 to ROS 2. This page will expand as ROS 2 packages are published.
:::

1. Set up an offboard PC on the same network as CBR-1.
2. Confirm connectivity to CBR-1's onboard compute over Ethernet or Wi-Fi.
3. Source your ROS 2 workspace and confirm CBR-1's topics are visible (`ros2 topic list`).
4. Teleoperate CBR-1 using a standard `teleop_twist_keyboard` or joystick node as a first software-driven test.

For current package availability and migration status, contact [support@cbirobotics.com](mailto:support@cbirobotics.com).
